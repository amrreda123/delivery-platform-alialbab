المسودة الديناميكية ومتابعة التطور البرمجي للهيكل الأساسي (Architecture Blueprint)
نسبة إنجاز البيئة الأساسية: 45%
الباك إند (Backend) PHP / Laravel

  • PHP 8.2 + Laravel 11

    تثبيت هيكل المشروع والـ MVC الأساسي.

  • Laravel Sanctum

    بناء وتأمين الـ APIs لتطبيق الموبايل.

  • Spatie Laravel Permission

    إدارة الأدوار والصلاحيات (عميل، مندوب، مدير).

  • Laravel Mail + Queues

    إرسال الإشعارات والإيميلات في الخلفية.

  • Intervention Image

    معالجة وضغط صور المنتجات والمندوبين.

الفرونت إند (Frontend) TALL Stack

  • Blade Templates

    تم تركيب قالب الصفحة الرئيسية بنجاح.

  • Livewire 3

    تم التثبيت وجاهز لبناء واجهات تفاعلية.

  • Alpine.js

    إضافة التفاعلات البسيطة في المتصفح (Modals, Dropdowns).

  • Tailwind CSS

    تم التثبيت والربط مع Vite و PostCSS.

  • Chart.js

    رسم المخططات البيانية في لوحة التحكم (Dashboard).

البنية التحتية والبيانات Infra & Data

  • MySQL 8

    قاعدة البيانات الأساسية (بانتظار بناء الجداول).

  • Redis

    الكاش (Cache)، الجلسات (Sessions)، وإدارة الطوابير (Queues).

  • Laravel Storage

    نظام إدارة الملفات والصور محلياً.

  • Cloudinary (CDN)

    رفع وتحسين الصور سحابياً لتسريع التصفح (اختياري).

أدوات التطوير والجودة Dev Experience

  • Laravel Telescope

    تم التثبيت لمراقبة الطلبات والاستعلامات.

  • Pest PHP

    تم التهيئة لكتابة الاختبارات المؤتمتة.

  • Laravel Pint

    تنسيق الكود تلقائياً وتوحيد المعايير القياسية.

  • Laravel Debugbar

    تم التثبيت لتحليل أداء الاستعلامات محلياً.
